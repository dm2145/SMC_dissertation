# Evaluating Smart Money Concepts (SMC)

Research code for an undergraduate dissertation at Heriot-Watt University.
**Not financial advice and not intended for live trading.**

## Feasibility prototype (D1)
`smc_feasibility.py` runs on simulated prices only. It tests pattern
detection, a hindsight (truncation) test, matched random entries and
statistical power.

### Run
    pip install numpy pandas matplotlib
    python smc_feasibility.py

Results are saved to `results/`.
